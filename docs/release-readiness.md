# Estado de distribución

Syka Recorder usa su repositorio público `SikJa/syka-recorder`, con instalador Windows x64 y metadatos para actualizaciones estables.

- Código, licencias e historia de Recordly conservados; créditos bilingües.
- Recorder y Studio permanecen en repositorios separados.
- QA, perfiles, grabaciones y handoffs locales quedan fuera de Git.
- Paquetes nativos de Studio con medios relativos, máscaras, sombras y fondo.
- Descubrimiento de Studio por instalación, sin rutas de la PC del desarrollador.
- Compilación local y pruebas de componentes no equivalen a validar otra PC.
- Firma Authenticode y prueba en Windows limpio quedan pendientes.
- El primer instalador configura el feed. La actualización completa entre dos versiones públicas se debe comprobar al preparar la siguiente release.

Ver [cómo publicar](releases.md), [portabilidad](studio-transfer.md) y [créditos](../CREDITS.md).
